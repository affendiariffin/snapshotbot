Record your own games ⇩ Download the token
  1. Install — put the file in Documents\My Games\Tabletop Simulator\Saves\Saved Objects (any subfolder is fine).
  2. Spawn — on an LCT table, the host loads it via Objects → Saved Objects and drops it anywhere. No setup, no buttons.
  3. Play — the token finds the table and posts your replay link in chat (and a Notebook tab) within seconds, then records the whole game by itself. Open the link mid-game for a live scoreboard.
  4. Keep — finished games appear on this page for 30 days (newest 10 kept); use download on any game for a permanent offline copy that works without this site.
Notes:
  • LCT mod only — the token does nothing on other tables.
  • Current version {{ token_version }} — hover your token in TTS to see its version; it announces in chat when a newer one is out. Redownload & replace the file to update.
  • Up to 3 tables record at once — at capacity the token says so in chat and retries by itself.
